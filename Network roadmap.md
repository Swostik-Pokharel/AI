# **Networking Basics Pre-Uni Roadmap**

### **1. Networking Fundamentals**

- What is a network? LAN, WAN, Internet
    
- Clients and servers
    
- IP addresses (IPv4 basics)
    
- Ports and sockets
    
- Protocols overview: TCP, UDP, HTTP, HTTPS
    
- DNS basics (how domain names map to IP addresses)
    

---

### **2. OSI & TCP/IP Models**

- **OSI 7 layers** (Physical, Data Link, Network, Transport, Session, Presentation, Application)
    
- **TCP/IP stack** (Application, Transport, Internet, Network Access)
    
- Mapping protocols to layers (e.g., HTTP → Application, TCP → Transport)
    

---

### **3. HTTP & Web Basics**

- Request/Response model
    
- HTTP methods: GET, POST, PUT, DELETE, PATCH
    
- Status codes (200, 404, 500, etc.)
    
- Headers, body, query parameters
    
- RESTful principles (basic understanding for APIs)
    

---

### **4. Sockets & Basic Networking in Python**

- Concept of sockets (client-server communication)
    
- TCP vs UDP sockets
    
- Simple Python networking libraries: `socket`, `requests`, `http.server`
    
- Conceptual understanding of binding, listening, connecting, sending/receiving
    

---

### **5. APIs and Web Services Basics**

- What is an API? (Application Programming Interface)
    
- REST APIs vs GraphQL (overview)
    
- JSON as the common data format
    
- Making HTTP requests with Python (`requests` library)
    
- Basics of routing (endpoints, parameters)
    

---

### **6. Optional / Advanced Networking Concepts**

- Firewalls, NAT, and port forwarding basics
    
- SSL/TLS basics (HTTPS)
    
- Introduction to client-server architecture patterns
    
- Introduction to cloud APIs (optional, conceptual)
    

---

### **7. Suggested Study Path**

1. Start with **network fundamentals and OSI/TCP-IP**
    
2. Learn **HTTP & request-response flow**
    
3. Explore **Python sockets and `requests` library**
    
4. Study **REST APIs and JSON data handling**
    
5. Optional: look at **security basics (HTTPS/SSL)**
    

---
